# Tic-Tac-Toe

A beginner-friendly, two-player Tic-Tac-Toe game written in Python.
The game runs in your terminal and requires no external libraries.

## Features

- Two-player gameplay (X and O)
- Win and draw detection
- Input validation
- Option to play multiple rounds
- Simple, readable Python code

## Requirements

- Python 3.8 or later
- A terminal or command prompt

No additional packages are required.

## How to Run

1. Open a terminal.
2. Navigate to the project folder.
3. Run the following command:

   ```bash
   python main.py
   ```

   On some systems, use:

   ```bash
   python3 main.py
   ```

## How to Play

1. Player X goes first.
2. The board has nine positions numbered 1 to 9.
3. Enter the number of the position where you want to place your mark.
4. Players take turns placing X and O.
5. The first player to get three marks in a row, column,
   or diagonal wins.
6. If all nine positions are filled and nobody wins, the
   game ends in a draw.
7. Choose `y` when asked to play another round.

## Example Board

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```
